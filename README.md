# MaaPA 猛獸派對釣魚助手

《猛獸派對》（Party Animals）的自動釣魚工具：自動創房、全自動釣魚（買魚餌、賣魚到每日上限）、原地釣魚、小屋掛機、領取獎勵。
以 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 製作，執行器是修改版 [MXU](https://github.com/MistEO/MXU)。

## 下載

到 [Releases](../../releases) 下載最新的 `MaaPA-win-x86_64-<版本>.zip`。
GitHub 太慢時，執行器內建的更新會自動改從 `dl.vstorm.cc` 下載，兩邊的檔案相同（附 SHA256）。

## 需求

- Windows 10／11 64 位元
- 遊戲視窗 16:9（建議 1280×720 以上）

## 使用

1. 解壓到一個新的資料夾（路徑不要有特殊權限限制，例如不要放在 `C:\Program Files`）。
2. 開啟 `MaaPA.exe`，輸入卡密登入。
3. 選任務、設定選項後開始。
4. 有新版時執行器會提示更新；你的設定與紀錄（`config/`、`data/`）更新後會保留。
